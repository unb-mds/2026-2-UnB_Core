# UNB CORE

Base de conhecimento acadêmica colaborativa da Universidade de Brasília (UnB),
com conteúdos organizados por curso e disciplina.

## Status do projeto

**Fase atual: MVP publicado.** O frontend está hospedado no Vercel, a API no Render e o banco de dados no Neon. O sistema oferece autenticação, rotas acadêmicas, contribuições, moderação, gestão de usuários e recuperação de senha. Os cursos e as disciplinas são obtidos por um crawler do SIGAA público.

## Stack
 
- **Back-end**: Python com FastAPI
- **Front-end**: JavaScript com React
- **Banco de dados**: PostgreSQL com migrações Alembic
- **Hospedagem**: Vercel (frontend), Render (API) e Neon (banco)
- **Testes**: pytest no backend e Vitest com Testing Library no frontend
