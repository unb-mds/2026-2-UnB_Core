# Política de Segurança

## Relatar Vulnerabilidades
Para relatar problemas de segurança ou vulnerabilidades no UNB Core, envie um e-mail para joaovithorcama@gmail.com. Não relate vulnerabilidades em issues públicas no GitHub,
pull requests, discussões ou qualquer outro canal público.

Os relatórios devem incluir:

* Descrição
* Versão afetada
* Passos para reproduzir o problema
* Impacto identificado
* Prova de conceito (PoC): de preferência um vídeo, pois isso agiliza a validação.

**Confidencialidade**: Nenhuma informação relativa a uma vulnerabilidade relatada 
poderá ser divulgada publicamente, no todo ou em parte, até que uma correção tenha 
sido lançada e a UNB Core tenha divulgado formalmente a vulnerabilidade.

## Divulgação

Estamos comprometidos em:

* Validar e corrigir vulnerabilidades de forma responsável.
* Notificar os usuários quando uma atualização de segurança for lançada.
* Agradecer formalmente aos contribuidores que ajudam a melhorar a segurança do UNB Core.

**Obrigado por nos ajudar a manter este projeto seguro para todos.**
